# 潜入三星藏宝阁

像素风网页小游戏（纯 HTML / CSS / JS）。

## 在线游玩（点这个）

**https://dirtyangel817.github.io/sanxing-cangbaoge/**

> 注意：`github.com/...` 是代码仓库说明页；`github.io/...` 才是游戏。

## 本地打开

双击 `index.html`，或：

```bash
python -m http.server 5173
```

## 操作

- WASD 移动 · 空格跳 · 武器自动攻击 · P/Esc 暂停
- 关卡结束后进入商店，购买后点「进入下一关」
